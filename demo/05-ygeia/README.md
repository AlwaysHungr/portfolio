# Τεχνητή Νοημοσύνη στην Υγεία — Διαδραστική HTML5 Παρουσίαση

Διαδραστικό περιβάλλον ηλεκτρονικής μάθησης που προέκυψε από τη μετατροπή των 10 αρχείων
PowerPoint του μαθήματος (6 ενότητες, ~520 αρχικές διαφάνειες). **Κάθε ενότητα είναι
ξεχωριστό αρχείο HTML** με κοινό σχεδιαστικό σύστημα, και μια κεντρική σελίδα επιλογής
τις συνδέει. Λειτουργεί πλήρως τοπικά, χωρίς server και χωρίς εξωτερικές εξαρτήσεις.

## Εκκίνηση

- Ανοίξτε το **`index.html`** με διπλό κλικ → κεντρική σελίδα επιλογής ενότητας.
- Ή ανοίξτε απευθείας μια ενότητα: **`enotita1.html` … `enotita6.html`**.

| Αρχείο | Ενότητα | Διαφάνειες |
|---|---|---|
| `enotita1.html` | Τεχνητή Νοημοσύνη και Εφαρμογές | 21 |
| `enotita2.html` | ΤΝ για Αναγνώριση Απειλητικών Καταστάσεων και Διάγνωση Ασθενειών | 35 |
| `enotita3.html` | Απεικονιστικές Μέθοδοι | 54 |
| `enotita4.html` | Γενεσιουργός Τεχνητή Νοημοσύνη στην Υγεία | 46 |
| `enotita5.html` | Προσωποποιημένη Διαχείριση Ασθενή και Βέλτιστη Θεραπευτική Στρατηγική | 59 |
| `enotita6.html` | Αξιόπιστη Τεχνητή Νοημοσύνη | 53 |

Η πρόοδος (ποιες διαφάνειες έχετε δει, τελευταία θέση ανά ενότητα) αποθηκεύεται αυτόματα
στο `localStorage` του browser. Ανοίγοντας ξανά μια ενότητα επιστρέφετε εκεί που σταματήσατε.

## Δομή αρχείων

```
elearning-app/
├── index.html          ← κεντρική σελίδα επιλογής ενότητας (με πρόοδο ανά ενότητα)
├── enotita1.html       ← Ενότητα 1 (αυτόνομη σελίδα παρουσίασης)
├── enotita2.html … enotita6.html
├── README.md
├── serve.js            ← προαιρετικός mini server για ανάπτυξη (ΔΕΝ χρειάζεται για χρήση)
├── css/
│   └── styles.css      ← κοινό σχεδιαστικό σύστημα όλων των σελίδων
├── js/
│   └── app.js          ← μηχανή παρουσίασης: πλοήγηση, renderer μπλοκ, πρόοδος
├── data/
│   ├── modules.js      ← μεταδεδομένα των 6 ενοτήτων (τίτλοι, περιγραφές, εικονίδια)
│   ├── content-e1.js   ← περιεχόμενο Ενότητας 1
│   ├── content-e2.js   ← περιεχόμενο Ενότητας 2
│   ├── content-e3-1.js / content-e3-2.js  ← Ενότητα 3 (τα 2 αρχικά PPT)
│   ├── ...             ← αντίστοιχα για Ενότητες 4, 5, 6
└── assets/
    └── images/
        ├── e1/ … e6/   ← ΟΛΕΣ οι εικόνες των αρχικών PowerPoint (84), ανά ενότητα
```

Κάθε `enotitaN.html` φορτώνει μόνο τα δικά της δεδομένα (`data/content-eN*.js`) και δηλώνει
`window.SINGLE_MODULE = 'eN'`. Το `index.html` φορτώνει όλα τα δεδομένα (για τους μετρητές
προόδου) και δηλώνει `window.LANDING_MODE = true`.

## Πώς αλλάζω ή προσθέτω περιεχόμενο

Το περιεχόμενο είναι δεδομένα, όχι HTML: κάθε αρχείο `data/content-*.js` προσθέτει
«διαφάνειες» σε μια ενότητα με την κλήση:

```js
window.__addSlides('e1', [
  {
    id: 'e1-s01',
    section: 'Εισαγωγή',            // ομαδοποίηση στο πλαϊνό μενού
    title: 'Τίτλος διαφάνειας',
    blocks: [
      { type: 'paragraph', html: 'Κείμενο με <strong>HTML</strong>…' },
      { type: 'image', src: 'assets/images/e1/p1_image1.jpg', alt: '…', caption: '…' }
    ]
  }
]);
```

- **Αλλαγή κειμένου**: επεξεργαστείτε το αντίστοιχο `content-*.js` με οποιονδήποτε editor
  (κωδικοποίηση UTF-8) και ανανεώστε τη σελίδα.
- **Νέα διαφάνεια**: προσθέστε ένα ακόμη αντικείμενο στη λίστα, στη θέση που θέλετε.
- **Νέα εικόνα**: αντιγράψτε την στο `assets/images/<ενότητα>/` και προσθέστε μπλοκ `image`.

### Διαθέσιμοι τύποι μπλοκ

`heading, paragraph, html, list, callout (info/tip/example/warn/definition/activity),
cards, stats, image, table, accordion, tabs, flipcards, timeline, steps, compare,
reveal, hotspots, quote, resources, references`

Τα ακριβή πεδία κάθε τύπου φαίνονται στα υπάρχοντα αρχεία `content-*.js` και στους
renderers του `js/app.js` (αντικείμενο `blockRenderers`).

## Πώς προσθέτω νέα ενότητα

1. Στο `data/modules.js` προσθέστε ένα αντικείμενο στη λίστα `modules`
   (id π.χ. `'e7'`, `number: 7`, τίτλο, περιγραφή, `icon`, `accent`).
2. Δημιουργήστε αρχείο `data/content-e7.js` που καλεί `window.__addSlides('e7', [...])`.
3. Αντιγράψτε ένα υπάρχον `enotitaN.html` σε `enotita7.html` και αλλάξτε:
   τον τίτλο `<title>`, τα `<script src="data/content-...">` ώστε να φορτώνει το
   `content-e7.js`, και τη γραμμή `window.SINGLE_MODULE = 'e7';`.
4. Στο `index.html` προσθέστε `<script src="data/content-e7.js"></script>` πριν το
   `js/app.js` (για να εμφανίζεται η κάρτα της νέας ενότητας με σωστό μετρητή).
5. (Προαιρετικά) φάκελο εικόνων `assets/images/e7/`.

## Λειτουργίες που υλοποιήθηκαν

- **Κεντρική σελίδα** (`index.html`) με κάρτες ενοτήτων, ποσοστό προόδου ανά ενότητα,
  ένδειξη ολοκλήρωσης (✓) και κουμπί «Συνέχεια» στην τελευταία ενότητα που ανοίχθηκε.
- **Πλοήγηση ανά ενότητα**: πλαϊνό μενού με υποενότητες, ένδειξη τρέχουσας και επισκεφθείσας
  διαφάνειας, κουμπιά «Προηγούμενο/Επόμενο», βέλη πληκτρολογίου, γραμμή προόδου, μετρητής
  διαφανειών, κουμπί αρχικής, πλήρης οθόνη, εμφάνιση/απόκρυψη μενού.
- **Μέγεθος γραμματοσειράς (A− / A+)**: κουμπιά στην επάνω μπάρα, 7 επίπεδα (85%–135%).
  Η προτίμηση αποθηκεύεται στο `localStorage` και ισχύει σε όλες τις σελίδες/επισκέψεις.
- **Διαδραστικά στοιχεία περιεχομένου**: tabs, accordions, flip cards (γλωσσάρια), timelines,
  βήματα διαδικασιών, συγκρίσεις, κάρτες αποκάλυψης, hotspots σε εικόνες, callouts
  (ορισμοί, παραδείγματα, δραστηριότητες), πίνακες, πηγές/βιβλιογραφία.
- **Αποθήκευση προόδου** σε `localStorage` (ανά ενότητα) και επαναφορά στην τελευταία
  διαφάνεια όταν ξανανοίξει η σελίδα.
- **Προσβασιμότητα**: πλοήγηση με πληκτρολόγιο, ορατό focus, ARIA labels/roles, alt κείμενα,
  επαρκής αντίθεση, σεβασμός του `prefers-reduced-motion`, skip link.
- **Responsive** σχεδιασμός για desktop/laptop/tablet/κινητό (συρόμενο μενού, χωρίς
  οριζόντιο scrolling) και **χειρισμός σφαλμάτων** για εικόνες που δεν φορτώνονται.
