# Ενότητα 1: Στρατηγικό και Κανονιστικό Πλαίσιο

Διαδραστικό εκπαιδευτικό μάθημα (slides) για την **Τεχνητή Νοημοσύνη στη Δημόσια Διοίκηση**,
απευθυνόμενο σε υπαλλήλους και στελέχη υπουργείων, δήμων, περιφερειών, δημόσιων οργανισμών
και εποπτευόμενων φορέων του Ελληνικού Δημοσίου.

## Προβολή

Δεν απαιτείται backend, εγκατάσταση ή σύνδεση στο διαδίκτυο.

1. Ανοίξτε τον φάκελο `enotita-1`.
2. Κάντε **διπλό κλικ στο `index.html`**, ανοίγει στον προεπιλεγμένο browser
   (Chrome, Edge, Firefox).

Εναλλακτικά, για τοπικό web server (προαιρετικό):

```bash
# από τον φάκελο enotita-1
python -m http.server 8000      # ή:  npx serve .
# άνοιγμα: http://localhost:8000
```

## Πλοήγηση

| Ενέργεια | Τρόπος |
|---|---|
| Επόμενη / προηγούμενη διαφάνεια | Κουμπιά **Επόμενο / Προηγούμενο** ή πλήκτρα **← →** |
| Πρώτη / τελευταία διαφάνεια | **Home** / **End** |
| Μετάβαση σε ενότητα | Κλικ σε τίτλο στο πλαϊνό μενού (sidebar) |
| Εμφάνιση/απόκρυψη sidebar | Κουμπί με τις τρεις γραμμές (πάνω αριστερά) |
| Φωτεινό / σκούρο θέμα | Κουμπί ήλιος/φεγγάρι (πάνω δεξιά), αποθηκεύεται τοπικά |

Πάνω υπάρχει **μπάρα προόδου** και **αρίθμηση διαφάνειας** (π.χ. `03 / 30`).

## Διαδράσεις (όχι quiz)

Όλες οι διαδράσεις βοηθούν την κατανόηση, **δεν υπάρχει αξιολόγηση,
σωστό/λάθος ή βαθμολόγηση**:

- **Click-to-reveal κάρτες** για βασικές έννοιες (π.χ. οι 3 ορισμοί ψηφιακού κράτους)
- **Tabs** για σύγκριση ρόλων, φορέων και κατηγοριών
- **Accordions** για κανονιστικά πλαίσια, κριτήρια και στοιχεία τεκμηρίωσης
- **Timelines** για διαδικασίες και στάδια
- **Callout boxes** (πληροφορία / προσοχή / κίνδυνος)
- **Scenario panels** χωρίς ερώτηση ή βαθμολόγηση
- **Interactive checklist** για ασφαλή χρήση ΤΝ σε υπηρεσιακό περιβάλλον
- **Expandable glossary** όρων
- **Key takeaway** slides στο τέλος κάθε υποενότητας
- **Reflection cards** (μόνο ως σκέψη, χωρίς απάντηση)

## Προσβασιμότητα

- Πλήρης πλοήγηση με πληκτρολόγιο και `aria-label` σε όλα τα κουμπιά
- Καλή αντίθεση χρωμάτων· το νόημα δεν βασίζεται μόνο στο χρώμα (εικονίδια + ετικέτες)
- Σεβασμός στο `prefers-reduced-motion`
- Σύνδεσμος «μετάβαση στο περιεχόμενο» (skip link)


## Επαναχρησιμοποίηση για τις υπόλοιπες ενότητες

Ο μηχανισμός είναι γενικός. Για νέα ενότητα:

1. Αντιγράψτε τον φάκελο `enotita-1` σε `enotita-2` κ.ο.κ.
2. Στο `script.js` αλλάξτε **μόνο** τα δεδομένα του πίνακα `SLIDES[]`
   (κλήσεις `S(group, nav, html)`), αξιοποιώντας τους ίδιους βοηθούς
   (`head`, `card`, `reveal`, `tabs`, `accordion`, `timeline`, `callout`,
   `scenario`, `checklist`, `takeaway`, `glossTerm`).
3. Ενημερώστε τον τίτλο στο `index.html` και την κεφαλίδα του sidebar.
